# Atlas — Global Country Explorer 🌍

A dynamic frontend application that fetches and displays country data using the REST Countries API. Built with network resilience in mind, the application features a seamless local fallback dataset to ensure 100% uptime even on restrictive networks.

This project was developed as **Task 3 (API Integration Project)** for the Frontend Development Internship at **Alfido Tech**.

## 🔗 Live Demo
[Click here to view the live project][(https://sayann143.github.io/Country-Explorer/)]

## ✨ Key Features
* **Dynamic Search & Filtering:** Search for specific countries by name or filter the grid by global region.
* **Network Resilience:** Implements a graceful fallback dataset that automatically loads if the primary REST Countries API is blocked by regional ISPs or strict browser extensions.
* **State Management:** Includes visual loading skeletons during data fetching and clean state transitions.
* **Responsive Grid UI:** Built with CSS Grid and Flexbox to ensure a seamless experience across desktop, tablet, and mobile devices.

## 🛠️ Tech Stack
* **HTML5 & CSS3:** Semantic structure and custom dark-theme styling.
* **Vanilla JavaScript:** DOM manipulation, event debouncing, and asynchronous API fetching.
* **REST Countries API:** External data source providing global JSON data.

## 🚀 How to Run Locally
1. Clone this repository: `git clone https://github.com/Sayann143/Country-Explorer.git`
2. Navigate to the project directory.
3. Open `index.html` in your browser or run via VS Code Live Server.
